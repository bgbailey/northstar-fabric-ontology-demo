# Support

## Sample notice

Northstar is an open-source sample demonstration and solution accelerator. It is **not** an official Microsoft product, commercial service, or supported Microsoft offering, and it carries no service-level agreement or warranty.

## How to get help

Support for this repository is provided on a best-effort community basis through **GitHub Issues only**:

- Search existing [GitHub Issues](https://github.com/bgbailey/northstar-fabric-ontology-demo/issues) before opening a new question or bug report.
- When reporting a bug, include your operating system, Python and Node.js versions, the command you ran, and the error output.
- Never paste credentials, tokens, certificates, or real demo tenant, workspace, or item identifiers into an issue.

## Security issues

Do not report security vulnerabilities in public GitHub Issues. Follow [SECURITY.md](SECURITY.md) to submit a private report through GitHub Private Vulnerability Reporting.

## Microsoft platform support

For product documentation and platform support covering Microsoft Fabric, Fabric IQ, Power BI, OneLake, Microsoft Foundry, or Copilot Studio, consult [Microsoft Learn](https://learn.microsoft.com/en-us/fabric/iq/overview) or open a support request through your Microsoft Azure or Microsoft Fabric support plan.
