# Public example status

The repository contains two synthetic native-ontology demonstration streams
and a guarded comparison/display application. See `demo-streams.md` for the
current run guide and `capabilities.md` for claim boundaries.

| Surface | Retained evidence |
|---|---|
| Executive ontology | Separate generation-2 item; two existing models, four entities, three relationships, fourteen source proxies and two Rules |
| Executive answer | Historical native-service answer with one synthetic review candidate and correct source homes, independently source-checked |
| Customer360 ontology | Eight models, 59 entities, 105 relationships, 64 source proxies and four Rules |
| Advanced application stories | Three historical pairs executed in both arms, with actual pre/postflight and common source state; 335 known metric values reviewed |
| Recorded fallback | Ten historical full-ontology pairs plus the separate executive native answer |

Recordings preserve original dates, PARTIAL qualifications and historical
failed arms. Public files are sanitized display projections; raw captures,
operator history, environment identities and authentication state are not shipped.
Provenance hashes continue to identify privately retained originals.

No source or workspace is provisioned by cloning this repository or opening a
recording. Live work in another environment requires that environment's own
supported capabilities, current approved identity, exact operation approvals
and source/native verification. Static documentation does not assert that a
local service is running.

## Evidence gaps / still thin

Managed-native internal execution, automatic source-AI inheritance and actual
Rule consideration remain unexposed. Advanced results are qualified partial
cohorts, not complete-population or causal conclusions. Offline checks do not
promote live experiments or establish current live readiness.
